# Release notes

Every release is published on [GitHub Releases](https://github.com/MoonlightLaboratory/rexarr/releases) with its
packages. The notes for each version:

| Version | What is in it |
| --- | --- |
| [0.1.7.0](release-notes/0.1.7.0.md) | System → Updates with the release notes in the UI, and the documentation site |
| [0.1.6.0](release-notes/0.1.6.0.md) | Disc audio tracks, rip estimates, library matching, specials and extras, verified Radarr / Sonarr imports, keeping the computer awake, adding missing titles |
| [0.1.5.0](release-notes/0.1.5.0.md) | New logo and name, four-part version numbers, disc ripping on by default, better disc matching |
| [0.1.4.1](release-notes/0.1.4.1.md) | Earlier release |

Versions are `major.backend.feature.minor` — see [Development → Versions](development.md#versions). While Rexarr is
in beta, read the notes before updating and take a backup (**System → Backup**) first.

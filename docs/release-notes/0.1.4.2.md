## Downloads

| Platform | File |
| --- | --- |
| Windows 10 / 11 | `win-x64-installer.exe` · portable `win-x64.zip` · 32-bit `win-x86-installer.exe` / `win-x86.zip` |
| macOS 11+ | Apple silicon `osx-arm64-app.zip` · Intel `osx-x64-app.zip` · terminal `osx-arm64.tar.gz` / `osx-x64.tar.gz` |
| Linux | `linux-x64.tar.gz` · `linux-arm64.tar.gz` · `linux-arm.tar.gz` · Alpine `linux-musl-x64.tar.gz` / `linux-musl-arm64.tar.gz` |
| FreeBSD | `freebsd-x64.tar.gz` (needs `pkg install node22`) |
| Docker | `docker pull ghcr.io/moonlightlaboratory/rexarr:0.1.4.2` |

Packages include Node.js; rexarr runs on **http://localhost:3939**. See the
[install guide](https://github.com/MoonlightLaboratory/rexarr/blob/main/docs/README.md#install-from-a-release).
The macOS app is not notarised: the first time, right-click `rexarr.app` → *Open*.

## New

- **Recommended tools page**: on first launch rexarr checks for FFmpeg (required), fre:ac, MakeMKV and slskd and shows
  how to install whichever is missing on your platform: winget, Homebrew or apt commands with a Copy button, and the
  official download pages. *Check again* re-detects after installing. It stays available under **System → Tools**.
- **Windows installer**: a new *Recommended tools* page. Tick a tool and its official download page opens when setup
  finishes; tools that are already installed are marked.

## Fixes

- fre:ac installed in its standard Windows folders (`Program Files\freac`) is now found without setting its path.

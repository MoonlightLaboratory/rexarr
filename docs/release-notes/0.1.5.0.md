## Downloads

| Platform | File |
| --- | --- |
| Windows 10 / 11 | `win-x64-installer.exe` · portable `win-x64.zip` · 32-bit `win-x86-installer.exe` / `win-x86.zip` |
| macOS 11+ | Apple silicon `osx-arm64-app.zip` · Intel `osx-x64-app.zip` · terminal `osx-arm64.tar.gz` / `osx-x64.tar.gz` |
| Linux | `linux-x64.tar.gz` · `linux-arm64.tar.gz` · `linux-arm.tar.gz` · Alpine `linux-musl-x64.tar.gz` / `linux-musl-arm64.tar.gz` |
| FreeBSD | `freebsd-x64.tar.gz` (needs `pkg install node22`) |
| Docker | `docker pull ghcr.io/moonlightlaboratory/rexarr:0.1.5.0` |

Packages include Node.js; Rexarr runs on **http://localhost:3939**. See the
[install guide](https://github.com/MoonlightLaboratory/rexarr/blob/main/docs/README.md#install-from-a-release).
The macOS app is not notarised: the first time, right-click `Rexarr.app` → *Open*.

## New

- **New logo**, and the name is now written **Rexarr**: a new icon for the Windows installer and the macOS app, the
  disc mark in the header and as the browser icon. File names, commands, paths and the Docker image stay lowercase.
  The macOS app is now `Rexarr.app`.
- **Version numbers** have four parts, `major.backend.feature.minor`: `0.0.0.X` for fixes, `0.0.X.0` for features,
  `0.X.0.0` for backend changes and `X.0.0.0` for a rewrite. See
  [CONTRIBUTING](https://github.com/MoonlightLaboratory/rexarr/blob/main/CONTRIBUTING.md#versions).

## Fixes

- **Tools that cannot start now say why.** An FFmpeg, fre:ac or MakeMKV binary built for another processor (an Intel
  build on an Apple silicon Mac without Rosetta) reported only "Unknown system error -86"; System → Status and the
  health checks now explain it, as they do for missing files and files that are not executable.
- **Discs on macOS**: macOS mounts a DVD as soon as it is inserted, and MakeMKV could then only use "OS access mode",
  which fails on most discs – scans finished in a second with "No titles found on this disc". Rexarr now unmounts the
  volume (the disc stays in the drive) before scanning and ripping, and says so if MakeMKV still cannot open a disc.
- **Linux packages**: the launcher inside the `.tar.gz` was named `Rexarr` after the rebrand, so `rexarr/rexarr` did
  not exist on Linux. Fixed, and the packager now checks file names case-sensitively.

**Upgrading**: nothing to do. Windows installs over the old version, macOS and Linux replace the folder; your
settings and data stay where they are.

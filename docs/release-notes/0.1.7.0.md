## Downloads

| Platform | File |
| --- | --- |
| Windows 10 / 11 | `win-x64-installer.exe` · portable `win-x64.zip` · 32-bit `win-x86-installer.exe` / `win-x86.zip` |
| macOS 11+ | Apple silicon `osx-arm64-app.zip` · Intel `osx-x64-app.zip` · terminal `osx-arm64.tar.gz` / `osx-x64.tar.gz` |
| Linux | `linux-x64.tar.gz` · `linux-arm64.tar.gz` · `linux-arm.tar.gz` · Alpine `linux-musl-x64.tar.gz` / `linux-musl-arm64.tar.gz` |
| FreeBSD | `freebsd-x64.tar.gz` (needs `pkg install node22`) |
| Docker | `docker pull ghcr.io/moonlightlaboratory/rexarr:0.1.7.0` |

Packages include Node.js; Rexarr runs on **http://localhost:3939**. See the
[install guide](https://moonlightlaboratory.github.io/rexarr/getting-started/install/).
The macOS app is not notarised: the first time, right-click `Rexarr.app` → *Open*.

## New

- **System → Updates**: every release Rexarr has published, newest first, with its notes rendered in the UI —
  what is installed, what is newer, and what changed in between. The list is read from GitHub, cached for six
  hours, refreshed by the *Check for updates* task twice a day and by the *Check* button, and a new release is
  written to System → Events once. Rexarr still does not update itself: each newer release says how to install it
  for the way this instance was installed (package, Docker image, or source).

- **Documentation site**: the whole guide now lives at <https://moonlightlaboratory.github.io/rexarr/> — install
  and setup, every page of the UI, disc ripping end to end, a settings reference with the JSON key behind each
  field, the API, troubleshooting and development notes. It is built from `docs/` on every push.

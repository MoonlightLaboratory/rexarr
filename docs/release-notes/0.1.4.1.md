The first public release of rexarr: a remux-first transcoding companion for Radarr, Sonarr and Lidarr.

## Downloads

| Platform | File |
| --- | --- |
| Windows 10 / 11 | `win-x64-installer.exe` · portable `win-x64.zip` · 32-bit `win-x86-installer.exe` / `win-x86.zip` |
| macOS 11+ | Apple silicon `osx-arm64-app.zip` · Intel `osx-x64-app.zip` · terminal `osx-arm64.tar.gz` / `osx-x64.tar.gz` |
| Linux | `linux-x64.tar.gz` · `linux-arm64.tar.gz` · `linux-arm.tar.gz` · Alpine `linux-musl-x64.tar.gz` / `linux-musl-arm64.tar.gz` |
| FreeBSD | `freebsd-x64.tar.gz` (needs `pkg install node22`) |
| Docker | `docker pull ghcr.io/moonlightlaboratory/rexarr:0.1.4.1` |

Packages include Node.js. Install FFmpeg yourself (and fre:ac for music, MakeMKV for disc ripping); the Docker image
already has FFmpeg and fre:ac. Rexarr runs on **http://localhost:3939**. See the
[install guide](https://github.com/MoonlightLaboratory/rexarr/blob/main/docs/README.md#install-from-a-release).

The macOS app is not notarised: the first time, right-click `rexarr.app` → *Open*.

## Highlights

- **Transcoding** with FFmpeg profiles for x264, x265, SVT-AV1, libaom, VP9 and hardware encoders (VideoToolbox,
  NVENC, QuickSync, VAAPI, AMF), with presets for movies, TV and anime
- **Estimated output size** for every profile before you encode
- **Live preview** while encoding and a before / after comparison when done
- **Remux-first release search** through Radarr, Sonarr, Lidarr and Prowlarr, ranked by source quality
- **Auto transcode** of new remux imports, with webhooks for instant pick-up
- **Disc ripping** with MakeMKV from physical or virtual drives (ISO / BDMV / VIDEO_TS)
- **Music** with Lidarr and fre:ac: FLAC, MP3, Opus and Vorbis profiles, audio CD ripping with MusicBrainz, MQA
  detection, Soulseek (slskd) search, and automatic splitting of image + cue downloads
- **Local media**: finds movies, series and albums the \*arr apps do not manage, with TMDb, MusicBrainz and Cover
  Art Archive metadata
- **Smart search** across your library, TMDB / TVDB and AniDB
- **Safety**: queue pause, stall watchdog, free-space checks, network share health checks and scheduled backups

## Notes

- The default port is **3939** (7878 is Radarr's).
- The Docker image's fre:ac has no WavPack or Monkey's Audio encoder.

# Keyboard shortcuts

Press <kbd>?</kbd> anywhere to see the list without leaving the page.

| Keys | Goes to |
| --- | --- |
| <kbd>g</kbd> <kbd>h</kbd> | Home |
| <kbd>g</kbd> <kbd>m</kbd> | Movies |
| <kbd>g</kbd> <kbd>s</kbd> | Series |
| <kbd>g</kbd> <kbd>u</kbd> | Music |
| <kbd>g</kbd> <kbd>d</kbd> | Discs |
| <kbd>g</kbd> <kbd>a</kbd> | Activity |
| <kbd>g</kbd> <kbd>p</kbd> | Profiles |
| <kbd>g</kbd> <kbd>c</kbd> | Settings |
| <kbd>g</kbd> <kbd>y</kbd> | System |

| Keys | Does |
| --- | --- |
| <kbd>/</kbd> or <kbd>Ctrl/Cmd</kbd> + <kbd>K</kbd> | the search box |
| <kbd>?</kbd> | the list of shortcuts |
| <kbd>Esc</kbd> | closes what is open |

`g` then a letter, rather than a letter on its own: a bare <kbd>d</kbd> for Discs would fire on the first letter
of "Die Hard". **Nothing fires while you are typing** — in a text box, a search field or anything else that takes
text, the keys are the text. The chord expires after a second and a half, so a `g` you did not mean to press costs
nothing.

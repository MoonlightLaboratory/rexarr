Disc 3 is missing from this folder because nobody has read it. If the set runs 7 + 7 + 5 + 5 it is episodes
15–19, but that is arithmetic rather than a reading of the disc, and arithmetic is the thing this database
exists to replace. If you own it, open a pull request.

Note what the four discs do to the obvious guess: *(disc − 1) × episodes-on-this-disc + 1* gives 16 for disc 4,
which is four episodes out, because the first two discs hold seven each and the last two hold five.
